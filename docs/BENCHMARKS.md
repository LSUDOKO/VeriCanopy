## End-to-end scenario (`make e2e`, local Anvil)
Seed 3 demo projects + rejected overlap → score/prove/sign/submit → finalise → mint → retire → covered reversal + notification → fire-year shortfall → Frozen → upheld challenge + slashing. Each EZKL proof in the run is generated on this machine; see the log for per-step timings.
