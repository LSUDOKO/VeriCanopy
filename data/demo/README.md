# Demo projects

All four polygons were **drawn by the VeriCanopy team**. None is a real registered carbon project, and no output in this repository should be read as an assessment of any real project (see `docs/spec/AGENT_INSTRUCTIONS.md` rule 3).

| File | Purpose | Location | Expected behaviour |
|---|---|---|---|
| `project_A.geojson` | Honest project in intact forest | Pará, Brazil (~3.4°S, 54.8°W) | High integrity score |
| `project_B.geojson` | Inflated claimed baseline (4.5 %/yr) in a low-pressure area | Loreto, Peru (~3.9°S, 74.3°W) | Low score, large claim gap |
| `project_C.geojson` | Reversal demo | Manavgat district, Antalya, Türkiye (~36.8°N, 31.4°E), inside the area affected by the late-July 2021 wildfires `[VERIFY burned extent and dates against MODIS MCD64A1 before public use]` | Score drop + buffer burn in 2021 |
| `project_D_overlap.geojson` | Overlaps the eastern half of A | — | Registration rejected with `OverlapDetected` |

`samples/` holds fixture pixel samples generated by `ai/scripts/make_fixture_samples.py` with fixed seeds. They are **synthetic stand-ins** used when Earth Engine credentials are not configured; every output produced from them is labelled `provider: fixture`. With `EE_SERVICE_ACCOUNT_JSON` set, the same pipeline pulls real Hansen / Sentinel / GEDI / MODIS data.

`cells/` holds the H3 (res 8) cells, fine-cell Merkle roots and geometry hashes used by `scripts/seed.py`, produced by `python -m vericanopy_ai cells <file> --out <json>`.
