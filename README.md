# VeriCanopy

> Carbon credits that prove themselves.

Satellite AI scores every forest carbon credit against matched "twin" forest, a zkML proof shows the registered model produced the score, a geospatial registry blocks double-registration, credits update themselves when forests burn, anyone can challenge the inputs with a stake, and every record is signed with a NIST post-quantum signature.

Build in progress. See `docs/spec/` for the full specification and `docs/superpowers/plans/` for the implementation plan.
